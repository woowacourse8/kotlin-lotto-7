# 🎱 로또

## ✒️ 요구사항 정리
### 로또 구입
- 로또 구입 금액을 입력받는다.
- 구입 금액은 1,000원 단위로 입력받으며, 1,000원으로 나누어 떨어지지 않는 경우 예외 처리한다.
- 구입 금액에 해당하는 만큼 로또를 발행한다. (1장당 1,000원)

### 로또 발행
- 로또 번호의 숫자 범위는 1~45까지이다.
- 1개의 로또를 발행할 때 중복되지 않는 6개의 숫자를 뽑는다.
- 당첨 번호 추첨 시 중복되지 않는 숫자 6개와 보너스 번호 1개를 뽑는다.

### 당첨 번호 입력
- 당첨 번호를 입력받는다. (번호는 쉼표(,)를 기준으로 구분)
- 보너스 번호를 입력 받는다.

### 결과 확인
- 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 계산하고 출력해야 한다.
- 당첨 기준과 금액은 아래와 같다.
  - 3개 일치 (5,000원)
  - 4개 일치 (50,000원)
  - 5개 일치 (1,500,000원)
  - 5개 일치, 보너스 볼 일치 (30,000,000원)
  - 6개 일치 (2,000,000,000원)

### 예외 처리
- 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨다.
- `[ERROR]`로 시작하는 에러 메시지를 출력 후 그 부분부터 입력을 다시 받는다.

### 실행 결과 예시
```
구입금액을 입력해 주세요.
8000

8개를 구매했습니다.
[8, 21, 23, 41, 42, 43]
[3, 5, 11, 16, 32, 38]
[7, 11, 16, 35, 36, 44]
[1, 8, 11, 31, 41, 42]
[13, 14, 16, 38, 42, 45]
[7, 11, 30, 40, 42, 43]
[2, 13, 22, 32, 38, 45]
[1, 3, 5, 14, 22, 45]

당첨 번호를 입력해 주세요.
1,2,3,4,5,6

보너스 번호를 입력해 주세요.
7

당첨 통계
---
3개 일치 (5,000원) - 1개

총 수익률은 62.5%입니다.
```

## 📝 구현할 기능
### 입력
- [ ] 구입금액 입력 (1,000원 단위)
- [ ] 당첨번호 입력 (중복되지 않는 6개의 숫자)
- [ ] 보너스번호 입력 (당첨번호와 중복되지 않는 1개의 숫자)

### 출력
- [ ] 구입금액 입력 안내 문구 출력
- [ ] 구매 결과 문구 출력
- [ ] 구매한 로또 번호 출력 (중복되지 않는 6개의 숫자)
- [ ] 당첨번호 입력 안내 문구 출력
- [ ] 보너스번호 입력 안내 문구 출력
- [ ] 당첨 통계, 일치 내역, 총 수익률 출력
- [ ] 오류 메시지 출력

### 로또 머신
- [ ] 1~45 사이의 중복되지 않는 6개의 랜덤 숫자 뽑기
- [ ] 구입 금액이 유효한지 확인
- [ ] 구매한 로또의 수익률을 계산하여 통계

### 예외 사항
- [ ] 구입금액이 1,000원으로 나누어 떨어지지 않는 경우
- [ ] 구입금액이 1,000원 이하인 경우
- [ ] 당첨번호가 중복되는 경우
- [ ] 보너스번호와 당첨번호가 중복되는 경우
- [ ] 당첨번호와 보너스번호가 1~45의 범위를 벗어나는 경우
